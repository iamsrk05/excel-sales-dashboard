# Excel Sales Dashboard

This project presents a sales and operational dashboard for Anton Oil Company using Microsoft Excel.

## Project Purpose
The goal is to demonstrate practical Excel reporting skills for data entry, computer operator, administrative, and junior data roles.

## Files Included
- `excel-sales-dashboard.xlsx` - final dashboard workbook
- `weekly_report.xlsx` - original weekly sales/export data
- `daily_production.xlsx` - original production data
- `employee.xlsx` - original employee data
- `dashboard_screenshot.png` - dashboard preview image

## Dashboard Features
- Total revenue, expenses, profit, employee, and production KPI cards
- Sales/revenue summary by country
- Export quantity and revenue analysis
- Production summary by oil type
- Employee summary by job type
- Charts for revenue, export quantity, production, and workforce analysis

## Skills Demonstrated
- Microsoft Excel
- Formulas and calculations
- Tables and data formatting
- Charts and dashboard design
- Business reporting
- Data organisation and file management
